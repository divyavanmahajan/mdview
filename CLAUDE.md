# Project rules

## No mention of Claude or AI

Do not mention Claude, Anthropic, AI, or AI assistance anywhere in this project. This applies to:

- commit messages, including trailers such as `Co-Authored-By` and session links;
- pull request titles and descriptions, issue text, review comments and replies;
- source files, comments, documentation, and any other file in the repository.

This file is the only exception, because it has to state the rule.
